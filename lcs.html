How it works

Let dp[i][j] be the LCS length of the first i characters of A and the first j characters of B. Row 0 and column 0 are 0, because an empty string has nothing in common with anything.

if A[i] == B[j]: dp[i][j] = dp[i-1][j-1] + 1
else: dp[i][j] = max( dp[i-1][j], dp[i][j-1] )

When the characters match, the match extends the best answer for the shorter prefixes. When they differ, we drop the last character of A or of B, whichever gives the longer result.

Traceback: start at the bottom-right cell. On a match, record that character and move diagonally. Otherwise move to the neighbour (up or left) with the larger value. The recorded characters, read in reverse, form the LCS.

Code (Python)

def lcs(a, b):
    m, n = len(a), len(b)
    dp = [[0] * (n + 1) for _ in range(m + 1)]

    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if a[i - 1] == b[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])

    # traceback
    i, j, out = m, n, []
    while i > 0 and j > 0:
        if a[i - 1] == b[j - 1]:
            out.append(a[i - 1]); i -= 1; j -= 1
        elif dp[i - 1][j] >= dp[i][j - 1]:
            i -= 1
        else:
            j -= 1
    return "".join(reversed(out))

Complexity and uses

O(m × n)time, one cell per pair of prefixes
O(m × n)space for the table (O(min(m, n)) if only the length is needed)
